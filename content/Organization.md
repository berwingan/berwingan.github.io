## Keeping the Garden Organized

1. Keep each note at its existing path where possible. Topic guides can link across folders, so a note does not need to move or be copied to fit another topic.
2. Give a new note a descriptive `title`. Keep its original `date` and `source` when available.
3. Use `draft: true` for unfinished material that should stay off the website. An `underconstruction` tag alone does not hide a page.
4. When a note is ready to publish, remove `draft: true` or set it to `false`, then add it to a relevant public topic guide. Public guides should link only to published pages.
5. Use a vault-relative path in wikilinks when filenames repeat, especially `index`, `Daft`, and `Picture to HTML`.
6. Keep attachments in their existing locations to preserve embeds. Quartz handles attachments separately from Markdown drafts; `draft: true` does not hide an attached file.
